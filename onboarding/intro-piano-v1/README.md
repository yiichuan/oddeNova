# intro-piano-v1

新手指引的练习案例。方案见 `docs/new-user-onboarding-plan.md`，运行时入口是
`src/onboarding/intro-piano-case.ts`。

| 项 | 值 |
| --- | --- |
| 基准曲 | `themes/beta-1.0/theme.{zh,en}.strudel.js`（直接引用，不复制） |
| 改编脚本 | `adapted.zh.strudel.js` / `adapted.en.strudel.js`，代码逐字相同，只有注释语言不同 |
| 改动 | 新增音层 `horizon_intro`（紧跟在 `horizon` 之后）；其余音层、`setcps(0.4)` 保持原样 |
| 新增音层触发范围 | cycle 0–4（0～10 秒），用 `filterWhen((t) => t < 4)`，不随 32 cycle 编排循环重现 |
| 必经试听窗口 | cycle 0–2（0～5 秒），原版与改编版相同 |
| 可选试听窗口 | cycle 0–5（0～12.5 秒） |
| 试听前预载音色 | `gm_pad_warm`（horizon 的 D/G 两组和弦音）、`gm_epiano1`（新增音层的音） |

## 已自动验证（`src/onboarding/__tests__/intro-piano-case.test.ts`）

- 两种语言的改编脚本去掉注释后逐行一致。
- 原有音层源码与全局速度不变，只多出 `horizon_intro`，且位于 `horizon` 之后。
- 用真实 Strudel 引擎求值两份完整脚本、查询到第 70 个 cycle（约 175 秒，跨过 80 秒循环点）：
  改编版比原版只多 15 个音，全部是 `gm_epiano1`、全部落在 cycle 0–4 内；其余所有音完全一致。
- 前 5 秒的新增音只用 D/A/C/E，5～10 秒只用 G/B/D/E，与 `horizon` 的和弦同步切换。

## 听感验收：尚未完成

以下必须由人实际试听后填写，未通过前不应上线（方案第 10 节）。
不达标时先调整 `horizon_intro` 的音区、包络、音符排列与音量，不改动原铺底；
改动后两份改编脚本要同步修改，测试会检查两者一致。

- [ ] 0～5 秒：整曲混音中，手机扬声器与耳机都能辨认新增的逐音琴声；请不熟悉曲子的人对比后描述差别
- [ ] 第 5 秒：琴音随原和弦切换，无错位、无不必要的不协和
- [ ] 8～12.5 秒：短音自然收束，脚步、低音、光点进入清楚，不拥挤
- [ ] 完整播放并跨过 80 秒：新增琴音没有再次出现，后续编排不变
- [ ] 无爆音、削波、突兀硬切；差异不是单纯来自总响度提升
- [ ] 当前 `gain(0.46)`、`adsr([0.004, 0.32, 0.12, 0.45])`、`lpf(3200)`、`room(0.22)` 为制作起点，试听后确认或调整
