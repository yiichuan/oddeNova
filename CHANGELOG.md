## [0.1.0] — 2026-05-21

### Added
- **AI Eval Framework** — automated agent evaluation pipeline with `agent-runner`, LLM judge evaluator, snapshot CLI, and human score import for regression tracking (`scripts/eval/`)
- **Vercel Analytics & Speed Insights** — production performance monitoring via `@vercel/analytics` and `@vercel/speed-insights`
- **Prompt Version Management** — structured system for versioning LLM prompts (`src/prompts/versions/v1.ts`, `active.ts` pointer, rollback runbook)
- **Share Link** — generate shareable URLs via Vercel Blob; `ShareButton` component with `api/share.ts` serverless handler
- **AI Coding Conventions** — `CLAUDE.md`, `AGENTS.md`, `.github/copilot-instructions.md` for consistent AI-assisted development
- **CI Auto-Release** — GitHub Actions workflow auto-generates `deploy/YYYY-MM-DD-N` release tags on push to `main`
- **CI Branch Cleanup** — scheduled workflows to clean up stale tags and zombie branches

### Changed
- **Top Action Bar** — replaced icon buttons with labelled text buttons; added "学习" (Learn) and "GitHub" quick-access links
- **GLM & Official Experience providers** — added GLM (智谱 AI) and 官方体验 (DeepSeek-backed demo) as selectable LLM providers in the provider switcher
- **Provider routing** — `llm-config.ts` centralised multi-provider resolution (Anthropic legacy path + OpenAI-compat path for DeepSeek / Kimi / OpenAI / GLM)

### Fixed
- Particle (galaxy) animation breaking after WAV export — restored animation state on live AudioContext rebuild
- iOS Safari auto-zoom on code editor focus — prevented via `font-size` CSS override
- Share link URL resolution edge case

## [0.0.1] — 2026-04-24 (Initial Build)

### Added
- **AI Agent loop** — multi-turn tool-calling loop (`loop.ts`, `executor.ts`) supporting Claude (Anthropic) and DeepSeek (OpenAI-compat)
- **Layer management tools** — `addLayer`, `removeLayer`, `replaceLayer`, `validate`, `commit`, `improvise` tool handlers with full JSON Schema definitions
- **Strudel integration** — compile, validate, and play Strudel patterns in-browser via WebAudio API; WAV export with OfflineAudioContext
- **Multi-session management** — create, switch, and delete independent music creation sessions with IndexedDB persistence (`useSessions`, `session-storage.ts`)
- **Code panel** — live Strudel code editor with CodeMirror and Strudel syntax highlighting
- **Agent thought sidebar** — real-time display of Agent reasoning steps and tool calls
- **AI suggestions** — context-aware next-step suggestions generated by LLM after each interaction
- **Undo history** — up to 50-step undo via session snapshots
- **Demo mode** — activate with `?demo=true` URL param; LLM simulator replays preset scenarios without an API key
- **Desktop app** — optional Electron wrapper with macOS `.dmg` packaging (`npm run dist:mac`)
- **Mobile-responsive layout** — adaptive three-panel → single-panel layout for iOS/Android
