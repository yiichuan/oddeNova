# 本地提示词工作台

在仓库根目录运行：

```bash
npm run dev:lab
```

命令会只监听 `127.0.0.1`，并打开 `/lab/prompts`。提示词工作台只在 Vite `lab` 模式出现；正式构建不包含本地文件接口。

## 使用

工作台会从当前正式提示词生成中文和英文的 v25 基线。基线只读；选择「从基线新建」后，可编辑和排序提示词模块、停用模块，并预览最终文本和相对基线的差异。人格提示词、人格名称和心情上下文作为渲染变量，不会写入正式提示词版本。

「单次调试」用所选模板运行真实 Agent。可以粘贴初始 Strudel 代码，在文本框中用空行分隔多轮指令（每轮支持多行）。运行结果会记录模型调用、工具调用、校验、耗时和 token 用量；试听需要手动点击。

「批量评测」预置仓库现有的单轮和多轮测试用例。可编辑测试集、建立代码包含断言、选择两份模板并指定重复次数。任务在当前浏览器标签中串行运行；每轮结束后保存检查点，关闭或刷新后可查看已保存部分并新建实验重跑；新标签页不会修改另一个标签页的运行状态。

使用其他服务商时，在左侧设置模型并输入 API Key。密钥只在当前页面内存中使用，不保存到实验记录。官方服务商继续使用本地开发服务已有的服务端密钥配置。

## 本地数据

提示词模板、测试集和实验快照写入 `.local/prompt-lab/`，该目录已加入 `.gitignore`。需要团队共享的测试集可以从该目录导出到仓库中受版本控制的测试夹具；个人草稿和运行记录留在本机。

提示词模板内容以明确文本模块保存，不执行 JavaScript。开发文件接口只接受本机同源请求，并将资源名限制为固定集合和安全 ID。

## 实验比较与回归

结果按用例、重复实验、对话轮次展示，单次调试使用单栏。每轮可配置交付预期、包含/不包含断言和人工检查点。用例级断言只在最后一轮检查；代码校验失败或缺少必要提交时停止该次重复，避免把无效代码传入下一轮。

用量统计累计本轮所有可见模型调用的输入和输出，覆盖意图分类和应用层重试；服务商未报告 usage 的请求标记为用量不完整，不能视为账单金额。提交成功、运行完成和自动断言通过分别展示。

A/B 详情可记录整体偏好、三个辅助维度、原因和采用结论。盲听将样本顺序随机固定，并隐藏模板与代码；揭示后保存该状态。人工评审独立存储，不与正在保存的执行记录争用 revision。

每轮结果提供“保存为回归用例”和“用这一步重新比较”。两者都复制该轮之前的代码与历史；固定输入模式下 A/B 从同一状态执行所选指令。回归用例保存在“问题回归集”，可补充断言和检查点。

初始化按 active 提示词版本建立只读基线，保留旧基线与旧实验。同一语言的基线内容变化时必须使用新的版本号，否则工作台会提示版本冲突。实验记录保存目的、改动说明、渲染提示词 SHA-256 和 Git 版本/本地修改状态。历史记录支持搜索和分批显示；新记录的调用 transcript 独立保存，展开时才读取。

旧结果缺少重复/轮次标识时保持原始顺序并标明未知，不推测实验边界，也不将旧 1–10 分换算成 A/B 胜负。

## 交互与结构基准

新增 15 个用例覆盖聊天确认、分步创作与编号选择、精准编辑、跨轮约束、时间窗口、和声发音结构、直接交付和错误修复。聊天或澄清轮预期为文字回复，创作轮预期提交代码。编辑与编号用例使用固定代码或历史，便于 A/B 从同一输入比较。初始化会补入缺少的内置测试集，保留已有测试集的本地编辑。

代码包含断言用于固定素材保留和已知错误排除；它们不能代替语义检查。时间窗口和发音密度须查询实际事件或试听验证，检查点文案、音层说明与收尾建议由人工检查。自动检查通过不代表所有音乐要求都已满足。

## 整合工作区

默认进入批量评测。左侧通过 A / B 切换编辑对应模板，保留模块编辑；模块管理、渲染变量和最终提示词预览可展开。只读基线可新建草稿，运行会使用当前编辑内容并保存实验快照，包含尚未手动保存的修改。

右侧用例表格可直接编辑名称和分类，点击“编辑详情”修改指令及检查条件。结果按用例和重复次数排列，在结果行内选择整体偏好，展开全宽“试听与评价”区域完成试听、盲听与备注记录。盲听未揭示时隐藏已有备注及偏好汇总，评审读取失败可点击“重新加载评价”恢复。单次调试通过顶部切换，历史实验通过“运行记录”打开。切换测试集会清空结果选择，避免把其他测试集的实验误认为当前结果；旧实验仍可从历史记录查看。

## 单模板批量运行与历史对比

批量评测默认选择一份提示词运行，可切换到 A/B 同时运行两份。单模板结果按用例和重复次数显示，可查看代码、试听、检查及调用记录。

在“运行记录”中，选择历史对比 A、B 来源并点击“创建历史对比（无需重新运行）”。支持已结束的单模板批量记录或旧 A/B 记录的任意一侧；失败、取消或中断记录的已有结果也可使用。对比会独立保存两侧快照及评价，刷新后可从历史对比分类打开。模型、思考、变量及版本等条件显示在来源详情中。

用例 ID、输入和检查条件相同时按重复序号配对；只有完整对话可评价。不同输入、缺失重复或旧格式结果保留在来源原始结果中供查看，不推断配对。没有可配对结果时不创建对比。“用这一步重新比较（重新运行）”仍会调用模型执行新的 A/B。
