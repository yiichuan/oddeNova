# 作品库设计

## 目标

让已登录用户把一次成功的 Strudel 创作收藏为独立、可长期查找、试听、导出和分享的作品，而不再依赖翻阅历史对话。

## 已确认的产品边界

- `创作` 与 `作品` 是桌面和移动端的一级导航；作品库是独立主工作区。
- 作品库只对登录用户可用。未登录用户仍看得到入口，点击后进入登录引导；不在访客 IndexedDB 中创建作品副本。
- 只有用户显式收藏某个已提交并可播放的版本，才会创建作品；不自动收藏，也不允许模型自行收藏。
- 作品是不可变资产：重命名可改变展示标题，但不会覆盖曲谱或创作记录。
- 收藏时保存标题、最终 Strudel 曲谱、固定的生成式封面种子、收藏时间，以及用户可见的创作记录。创作记录不保存 agent 内部思考、工具调用或中间 revision。
- 作品和普通会话完全独立。删除任一方不影响另一方。
- `查看创作记录` 只读展示作品内保存的对话和曲谱。`基于此创作` 从作品的曲谱创建一个新的普通会话，不继承原对话历史。
- 作品卡片点击后进入详情。卡片上的独立按钮负责试听；试听不改写当前编辑器或当前会话。应用只保留一个播放源，因此开始作品试听会停止此前的播放。
- 作品详情提供试听、查看创作记录、基于此创作、重命名、删除、导出 WAV 和分享。
- 第一版支持名称搜索和按最近收藏排序；不提供标签、描述、用户上传封面、AI 封面、曲谱文件导出或视频导出。
- 作品分享复用现有临时分享链接语义：链接 30 天后清理；打开链接直接导入一个新的普通会话，访客无需登录；分享负载不包含私有创作记录。

## 数据模型与持久化

新增独立的 `Work` 领域对象，而不是向 `Session` 添加可变收藏标记。它至少包含：

```ts
interface Work {
  id: string;
  title: string;
  code: string;
  coverSeed: string;
  record: {
    messages: ChatMessage[];
    code: string;
  };
  createdAt: number;
  updatedAt: number;
}
```

客户端仅在认证 owner 的 IndexedDB 缓存该用户的作品；云端 `public.works` 是权威来源。表采用 `user_id`、应用侧 `work_id`、`title`、`code`、`cover_seed`、`record` JSONB、`created_at`、`updated_at`，并采用与 `sessions` 相同的 RLS、JWT 校验和 `(user_id, updated_at desc)` 索引策略。作品 API 独立为 `/api/works` 与 `/api/works/[id]`，避免把会话和作品的所有权、删除规则混在一起。

创建、重命名、删除都必须先获得服务器确认，再更新客户端状态；失败时保留原状态并显示可理解的错误。作品加载失败可保留已知缓存，但不可把本地缓存当成访客作品库。

## UI 与交互

在现有布局上增加顶级 destination 状态：桌面侧栏顶部和移动端顶栏均显示 `创作` / `作品`。作品视图覆盖为全宽主工作区，而非历史抽屉或侧栏列表。

作品库使用响应式卡片网格：固定生成式封面、标题、收藏日期和独立播放/暂停控件。搜索只匹配标题，默认按收藏时间倒序。空状态强调登录用户可收藏作品；未登录的目的地显示登录引导。

详情页显示封面、标题与操作。导出沿用现有 WAV 导出流程和参数面板。分享创建新的、只含作品标题与曲谱的现有 share payload；不传 `record.messages`。接收端因此保留现有 URL 导入行为，但不会看到私人创作记录。

## 会话、播放与分享数据流

收藏操作从当前 session 的最后提交曲谱和已可见消息创建 `Work`，之后再无 session 引用。基于作品开始创作时，创建新 Session，并以作品代码作为初始代码；不复制记录消息到 LLM 对话历史。

作品试听通过既有 `useStrudel()` 服务运行快照代码，不调用 `sessions.setCurrentCode`。播放器本身是全局单例，切换到作品试听自然停止旧模式；返回创作页时编辑器仍显示原会话代码。

分享使用 30 天 Blob 机制，但需为 work-only payload 增加明确版本/种类标记。导入端识别该负载，创建普通会话时只写入标题、曲谱和一个面向用户的导入说明；不得把它误当作包含创作记录的完整会话分享。

## 测试与验收

- 纯函数和 repository 层覆盖：作品快照过滤可见消息、独立删除、登录守卫、云端成功/失败同步、分享 payload 不泄漏创作记录、导入创建独立会话。
- 组件测试覆盖：未登录引导、一级导航切换、搜索/排序、卡片的详情与试听控制、详情操作。
- 现有会话、访客分享导入、WAV 导出和历史面板回归测试必须继续通过。
- 手工 smoke test：登录后收藏一首歌，刷新后仍存在；删除原会话后仍能播放与查看创作记录；从作品新建会话不带旧对话；分享链接在无登录状态导入后可以试听。

## 非目标

- 不实现公开作品主页、长期链接、分享撤销。
- 不实现标签、文件/AI 封面、视频导出或外部曲谱文件导出。
- 不向访客账户或 localStorage 提供作品库缓存。
