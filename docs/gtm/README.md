# Event GTM and unit economics review

Use this blank kit to review one launch, workshop, pop-up or conference. It covers earned revenue, cash expense, deposits, reusable assets, in-kind support, people time, participation, product use and outcomes after the event.

1. Copy [the review template](Event_GTM_Finance_Review_Template.md) for one event and define its window, timezone, owner and decision.
2. Record authorized source references in `csv/sources.csv`, costs in `csv/cost_lines.csv`, and metric observations in `csv/metric_observations.csv`.
3. Check scope, unit, population and evidence for every key figure. Leave unsupported fields blank and name the missing source.
4. Keep completed reviews, financial records, API usage, participant information and raw exports in a team-approved private location.

The template separates actual cash expense from budget, paid status, deposits, asset allocation and opportunity cost. API requests, Agent turns, sessions, devices, people and physical outputs remain separate units. Report financial ROI only when revenue or net benefit can be attributed to the event.

This directory contains a reusable method and empty CSV headers. It contains no oddeNova event data.
