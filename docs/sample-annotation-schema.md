# 采样听感标注字段 v2.0

## 定稿范围

本版用于给采样生成模型初标、支持候选检索和专家逐项纠正。字段定义固定在 `sample-annotation-schema-v2.json`，词表或语义变化需要升级版本。当前专家评分工作台仍使用原有 rubric，本版试验结果单独保存。

## Review 结论

第一版把单击、单音、循环、人声和环境音放在同一个单选字段里。一次人声发声可以同时是单击，钢琴长音也可以是单次事件。本版将声源、事件结构和音高性独立记录。循环是否无缝可播放需要另行检测。

自由描述保留给摘要、具体声源候选、奏法和证据。用于筛选的亮度、厚度、起音、尾音和混响改用固定选项。质感标签固定词表，避免同义词堆积；奏法继续允许中文短词，以覆盖不同乐器。

先前讨论的统一高/中/低音区、BPM、根音、调性、来源品牌和无缝循环能力不交给通用音频模型强制填写。文件信息和实测值放入程序元数据，根音优先记录采样映射中的证据。乐器之间的音区参照不同，不用单个样本概括整台乐器音域。

## 模型填写的字段

| 字段组 | 内容 | 主要用途 |
| --- | --- | --- |
| `schema_version` | 固定 `2.0` | 解析和版本管理 |
| `summary_zh` | 100 字以内的听感摘要 | 候选展示与文本检索 |
| `source` | 固定家族、最多 3 个中文声源候选 | 大类召回、分类复核 |
| `structure` | 单事件、重复事件、乐句、连续纹理等；音高性另记 | 区分素材结构 |
| `timbre` | 亮度、厚度、质感词、可听失真 | 同类候选比较 |
| `envelope` | 起音、后续包络、事件尾音 | 选择紧凑、缓起、持续等声音 |
| `space` | 混响感 | 区分干声和空间尾音 |
| `performance` | 可听奏法、音高运动；不适用时 `null` | 区分拨弦、持续音、滑音等 |
| `rhythm` | 脉搏与节奏特征；单次事件时 `null` | 循环/乐句候选比较 |
| `usage_suggestions` | 最多 3 个编曲角色，每项附听感理由 | 软推荐，不能当成声音事实 |
| `review` | 按字段列不确定性、可听依据 | 专家复核与纠正 |

固定值使用英文标识，摘要、原因、奏法和声源候选使用中文。详细枚举和解释以 JSON Schema 为准。

## 不确定与不适用

枚举中的 `unknown` 表示无法判断；`not_applicable` 或可选对象的 `null` 表示该维度不适用。不要把未知填写成“均衡”“干声”“无失真”。空标签数组表示没有足够证据选择该词表中的词。

`varied` 表示素材中不同事件或时段存在明显差异。`body` 的厚度和 `brightness` 的亮度是相对可辨类别的听感，`tail` 也是听感档位；这些值未经听审校准，首阶段只参与同类软排序。音量、音高、文件总长度不能分别替代厚度、亮度和尾音判断。

乐器自身振动的长尾可以与混响共存，也可能独立存在。无法区分时将 `space.reverb` 填为 `unknown`。来源无法精确识别时允许宽类别和多个候选，不能用具体乐器的猜测继续推导奏法、设备或录音环境。

证据是模型报告的听觉观察，仍可能错误。记录的 `review` 不等于审核完成，也不使用模型自报百分比充当可信概率。

## 程序记录的字段

每条结果另附样本 ID、采样库与原始路径、音频 SHA-256、文件时长/声道数/采样率、模型与实际返回模型名、提示词和 Schema 哈希、调用参数、原始响应、用量、Schema 校验和人工审核状态。目录信息与听辨结果独立保存，审核前不互相覆盖。

## 12 样本复测条件

沿用第一轮 manifest 的 12 段音频，每份文件与上一轮保存的 SHA-256 比较。模型使用 `qwen3.8-omni-flash`，关闭思考、单次原音频输入，其他生成参数沿用默认。继续隐藏文件名、采样库、测量值和原标签，只更新字段和提示词。

结构合格和来源命名一致性分别统计。目录名称可作为冲突线索，不能替代听感真值。本次每个采样只运行一次，生成随机性仍会影响对比；也不据此宣称检索效果提升。

## 目录类别优先

有明确目录依据时，由整理流程显式填写 `catalogCategory`。标注脚本将类别作为上下文，使用 v2.1 听感输出结构。该结构省略 `source`，复核字段也不能引用 `source.family` 或 `source.candidates_zh`。原 v2.0 结构保留给匿名试验和类别未知的样本。

选样数据的 `category` 仅取自 `catalogCategory`。未知类别保持为空，模型候选单独保存在 `categoryCandidatesForReview`。旧版摘要、奏法和建议仍可能带入错误的来源猜测，因此选样导出只带结构化听感字段。校验未通过时，仍可保留目录类别，听感字段留空待复核。

这项规则由 [标注与选样策略](../scripts/sample-annotation-policy.mjs) 实现。试验中的 `catalogHint` 只是对照输入，不自动等同于已核对的目录类别。
