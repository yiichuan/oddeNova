# Mission: React

## 1. Why
oddeNova 是一个 React + TypeScript 应用（Vite、hooks、IndexedDB、WebAudio）。掌握 React 后，你能够自信地阅读、修改和扩展代码库——新增功能、修复 bug、理解组件架构，而不用对框架本身心存疑虑。

## 2. Success looks like
- 阅读 `src/` 中的任意组件，能解释它做什么以及为什么这样组织
- 使用 hooks、props 和 state 新增一个 React 组件，且符合现有代码库约定
- 解释 React 渲染周期、依赖数组以及组件何时会重新渲染
- 能调试 `useEffect` 中的闭包过期或依赖缺失问题

## 3. Constraints
- 自定进度，在工作区内学习
- 课程尽可能结合 oddeNova 代码库
- 使用 TypeScript 方言（不是纯 JS）

## 4. Out of scope
- React Native / 移动端
- Server Components / RSC（Next.js 专属）
- Redux 等大型状态管理库（oddeNova 使用 hooks + IndexedDB）
