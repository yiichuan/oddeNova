第一课：组件与 JSX 入门

系列：React 基础 · 术语表 · 预计用时：10 分钟

1. 你将学到什么

React 组件是一个返回 UI 的函数。这就是全部核心思想。你编写描述屏幕上应该显示什么的函数，React 负责把它放上去，并在数据变化时保持更新。

本课你将学到：

  • JSX 是什么，它与 JavaScript 的关系
  • 如何编写组件并渲染它
  • Props 如何让父组件向子组件传递数据
  • 如何在 oddeNova 代码库中识别这些模式

2. JSX：JavaScript 中的 HTML

JSX 是一种语法扩展，让你直接在 JavaScript 中书写看起来像 HTML 的标记。它不是模板语言——它编译为普通的 JavaScript 函数调用。

// 这段 JSX：
const element = <h1>Hello, world</h1>

// 编译为：
const element = React.createElement('h1', null, 'Hello, world')

// 结果是一个普通对象：
// { type: 'h1', props: { children: 'Hello, world' } }

关键洞察：每个 JSX 元素都是一个 JavaScript 表达式。你可以把它赋值给变量、作为参数传递、从函数返回、存进数组——因为它本质上就是一个对象。

为什么这很重要：在 React 中，你的 UI 就是 JavaScript。没有单独的模板文件，没有需要学习的特殊模板语言。如果你懂 JavaScript，你就知道如何操作 UI。

3. 编写组件

组件就是一个返回 JSX 的函数。按照约定，组件名以大写字母开头——这是 React 区分组件与 HTML 标签的方式。

// 一个简单的组件
function Greeting({ name }) {
  return <h1>Hello, {name}!</h1>
}

// 使用时看起来像 HTML 标签：
function App() {
  return <Greeting name="Ada" />
}

当 React 看到 <Greeting name="Ada" /> 时，它会调用 Greeting 函数，传入 { name: "Ada" } 作为参数。函数返回 JSX，React 将其渲染到 DOM 中。

Props：数据如何向下流动

函数参数中的 { name } 是解构的 props。Props 是父组件传递给子组件的输入。它们是只读的——组件接收 props 并使用它们，但绝不修改它们。

// Props 就是传给你函数的一个对象
function Button({ label, onClick, disabled }) {
  return (
    <button onClick={onClick} disabled={disabled}>
      {label}
    </button>
  )
}

// 父组件决定传什么：
function Toolbar() {
  return <Button label="Save" onClick={() => save()} disabled={false} />
}
数据向下流动：Props 总是从父到子。如果两个兄弟组件需要同一份数据，你把它"上提"到它们的共同父组件。我们会在后续课程中讲这个。

4. 需要记住的 JSX 规则

  1. 返回单个根元素。如果需要多个兄弟节点，用 Fragment 包裹：<>...</> 
    // 错误——两个根：
return <h1>Hi</h1> <p>...</p>

// 正确——一个根：
return (
  <>
    <h1>Hi</h1>
    <p>...</p>
  </>
)
  2. 每个标签都要闭合。<img />、<br /> 以及像 <Button /> 这样的组件必须自闭合。
  3. 用 className，不用 class。因为 JSX 是 JavaScript，class 是保留字。className 映射到 HTML 的 class 属性。
  4. 花括号切换到 JavaScript 模式。在 JSX 内部，{ } 让你嵌入任何 JavaScript 表达式。{count + 1}、{user.name}、{items.map(...)}——都合法。

5. 从 oddeNova 看真实代码

让我们看看这些概念如何出现在实际代码库中。在 oddeNova 中，src/App.tsx 是根组件。它接收用户的聊天输入并编排 agent 循环。像 ChatInput 这样的组件接收 props 并通过回调函数上报——正是上面的模式。

以下是你会在代码库中看到的简化版本：

// 简化自 oddeNova 的结构
function ChatInput({ onSend, disabled }: ChatInputProps) {
  return (
    <form onSubmit={(e) => {
      e.preventDefault()
      onSend()
    }}>
      <input type="text" disabled={disabled} />
      <button type="submit" disabled={disabled}>Send</button>
    </form>
  )
}

// App 把回调函数传下去：
function App() {
  const handleSend = () => { /* 运行 agent 循环 */ }
  return <ChatInput onSend={handleSend} disabled={false} />
}

注意：ChatInput 不知道发送时会发生什么——它只调用 onSend()。父组件（App）来决定。这种分离是 React 可组合性的核心。

6. 检查你的理解

测验：组件与 JSX

React 组件最终返回什么？

正确！组件返回一个 JSX 元素，它是一个描述屏幕上应显示内容的普通 JavaScript 对象。React 随后将其转化为 DOM 节点。

为什么组件名必须以大写字母开头？

正确！小写标签如 <div> 被视为 HTML 元素。大写标签如 <Greeting> 被视为组件引用。没有这个约定，React 无法区分两者。

组件能修改自己的 props 吗？

正确。Props 在设计上是只读的。如果组件需要改变一个值，应该使用 state（下一课）。如果父组件需要知道变化，子组件通过回调 prop 来通知。
