# React 学习资源

## 1. Knowledge

- [React 官方文档 — "Learn React"](https://react.dev/learn)
  React 18+ 的权威来源。交互式、写得好，覆盖 hooks、state、effects、渲染和 context。用途：几乎所有内容。大多数课程引用的主要来源。
- [React 官方文档 — "Thinking in React"](https://react.dev/learn/thinking-in-react)
  构建 React UI 的心智模型，逐步讲解：组件层级、静态版本、识别 state、数据流。用途：基础心智模型。
- [React 参考文档 — `useState`](https://react.dev/reference/react/useState)
  最常用 hook 的 API 参考。用途：精确行为、批处理、函数式更新。
- [React 参考文档 — `useEffect`](https://react.dev/reference/react/useEffect)
  Effect 的 API 参考。用途：依赖数组、清理函数、执行时机、常见陷阱。
- [React 参考文档 — `useRef`](https://react.dev/reference/react/useRef)
  Ref 的 API 参考。用途：不触发重新渲染的可变值、DOM 访问。
- [React 参考文档 — `useMemo` / `useCallback`](https://react.dev/reference/react/useMemo)
  记忆化 hooks 的 API 参考。用途：性能优化、引用相等性。
- [React 参考文档 — `useContext`](https://react.dev/reference/react/useContext)
  Context 的 API 参考。用途：避免 prop drilling、theme/provider 模式。
- [React 文档 — "You Might Not Need an Effect"](https://react.dev/learn/you-might-not-need-an-effect)
  关于何时不该使用 useEffect 的重要文章。用途：避免常见反模式。
- [React 文档 — "Preserving and Resetting State"](https://react.dev/learn/preserving-and-resetting-state)
  React 如何通过位置和 key 识别组件。用途：理解 state 为何重置、列表渲染、key prop。
